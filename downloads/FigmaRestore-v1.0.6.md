# FigmaRestore 1.0.6

## 超大日志高性能流式下载与毫秒级过滤

- **超大日志原生流式下载**：
  - 针对 50MB~100MB+ 的超大日志文件，升级为服务端解密落盘与客户端原生 HTTP 分块流式下载架构，避免内存毛刺与编解码溢出，百兆日志秒级落盘。
- **十万行日志异步过滤与 140+ 倍提速**：
  - 过滤结果重构为响应式存储属性与 O(1) 访问切片，视图重绘主线程开销归零；
  - 引入 200ms 输入防抖、协作式取消中断机制（`Task.isCancelled` 每 512 行快速退出）与批量更新防重入保护；
  - 业务关键词与 Tag 纳秒级短路匹配，消除多余数组分配，搜索体验丝滑无卡顿。
- **状态同步与旧数据清理闭环**：
  - 切换归档、产品或遇到不可解析文件时，统一全量重置已解析数据源与筛选缓存，杜绝上一份日志残留。

## 界面交互与视觉稳定性优化

- **全局按钮 Loading 高度锁定**：
  - 系统化消除 PlayBook、日志分析、引擎设置等模块在点击触发 Loading 转圈时按钮高度微增导致的界面跳动，严格锁定按钮尺寸与图标容器物理边界。
- **日志过滤栏与文件列表优化**：
  - 工具栏筛选区支持自适应水平滚动，防止窗口宽度较窄时被压缩；
  - 归档内部文件列表默认展示核心业务日志（XLOG 与播放器日志），自动精简 RTC 临时通道文件。

## 局域网协同与团队分发

- **局域网服务地址适配**：默认连接局域网统一 MCP 端点（`10.86.11.195:17890`），支持团队成员多机直接协同使用。
