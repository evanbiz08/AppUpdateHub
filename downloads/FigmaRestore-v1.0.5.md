# FigmaRestore 1.0.5

## 新增功能：客户端用户日志分析工作台

- **远程 xlog-mcp 极速直连**：全新上线「用户日志分析」工作台，直连远程 xlog-mcp 服务，支持按应用（Yoki 等）与用户 UID 实时拉取、解密与检索 Mars xlog 客户端日志。
- **高精度栅格排版与严格对齐**：
  - 日志时间列统一为 104pt 宽，精简为 `MM-dd HH:mm:ss`，隐藏冗余年份与毫秒；缺失时间行采用等宽透明占位；
  - 级别徽章列统一为 18pt 宽；
  - Tag 标签自适应排版：短 Tag 紧凑胶囊展示，长 Tag 智能微缩字体并超长省略（`..`），支持 Tooltip 悬浮提示与点击一键过滤；缺失 Tag 行等宽占位；
  - 日志正文起始 X 坐标严格锁齐在 269pt，多行文本时各列徽章保持顶部对齐（Top 锚定），阅读舒适度显著提升。
- **UID 上下文记忆与缓存秒开**：搜索日志归档后即使清空 UID 输入框，点击历史归档仍能通过上下文记忆直接从本地缓存秒开或远端拉取，彻底解决输入清空后的查询异常。
- **智能日期与归档命名解析**：增强对短时间归档命名（如 `19_2506182135.zip` 等）的提取与日期适配，归档列表完整展示归档年份与时间。
- **满屏沉浸式阅读模式**：进入日志工作台时支持提示切换「满屏模式」，充分利用屏幕高宽提升长日志查阅效率。

## 全局界面与视觉规范打磨

- **全流水日志分割线与字号优化**：Figma 还原流水日志、方案审查与代码审查日志统一增加清晰行分割线，调优行高与字体大小，长日志查阅一目了然。
- **固定深色主题**：App 界面颜色固定为优雅深色系主题，避免跟随系统外观动态变化造成颜色反差或异常。
- **系统等宽字体升级**：日志与代码展示全面采用 macOS 原生等宽字体，视觉层次更清晰。
- **侧边栏视觉统一**：修正侧边栏底部「Agent 配置」图标颜色与文本颜色，保持高质感协调一致。
- **网络传输安全适配**：配置应用网络传输安全规则（ATS），保障与远程 HTTP 服务的稳定连通。
