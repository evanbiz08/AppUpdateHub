# FigmaRestore 1.0.4

## PlayBook 维护与安全合规加固

- **Codex 审查只读沙箱加固**：初始审查阶段强制采用 `--sandbox read-only` 严格沙箱隔离，杜绝非受控写操作；仅在用户主动发起针对性微调时按需授予权限。
- **工作区还原防丢保护**：还原操作移除硬删除，自动执行 `git stash push --include-untracked` 将未提交与未跟踪文件完整暂存备份，随时可通过 `git stash pop` 原样恢复；界面增加系统二次确认弹窗。
- **Git 分支安全防护**：全面采用原生进程参数数组调用，杜绝 Shell 命令拼接与注入风险；前置白名单校验分支名格式。
- **审查严重级别一致性**：统一问题严重等级（`level` / `severity`）的写入规范与模型反序列化解析，消除 `nonDeterminable` 状态误判。
- **审查微调门禁逻辑补全**：修复复审门禁中缺少 High 等级判定的隐患，包含 High 级别问题时严格判定为 conditional 状态并阻止放行。
- **Telemetry 配置防覆写保护**：重构配置解析逻辑，明确区分文件不存在与文件损坏，严禁在解析失败时使用空字典覆写已有宿主配置，写入采用原子落盘。
- **远程更新真实比对**：检查更新时显式静默 fetch 远端追踪分支，确保本地 ahead/behind 差分完全实时准确。

## 交互体验与细节打磨

- **控制台整卡片响应与指针反馈**：底部执行控制台横向整行区域均支持点击展开/折叠，不再局限于左侧小标题，增加系统原生小手指针交互反馈。
- **控制台静默折叠**：所有后台异步维护与同步任务触发时控制台保持默认折叠，禁止自动弹起打扰。
- **消除统计页临界状态闪烁**：启动阶段前置异步预热 Telemetry 状态检测，切换时提供平滑加载占位，彻底消除初次打开时误触发未安装警告的瞬态闪烁。
