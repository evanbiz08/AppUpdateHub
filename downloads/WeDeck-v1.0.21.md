# Controller Agent 更新和发布

- 新增「SVGA 检查」：最多同时预览 4 个动效，可切换四种画布背景，也可在 Finder 中用 We Deck 打开 `.svga` 文件。
- 支持循环浏览帧缩略图。播放或拖动进度条时，列表实时跟随当前帧；点击任一缩略图可暂停并跳到该帧。
- 可查看当前帧的图层名称、原图和透明度，识别占位候选并单独显示图层；同时展示文件属性、解码耗时、位图内存、实绘帧率和渲染耗时。
- 新增离线 X Log 解密：支持 `.xlog` 和包含多个日志的 ZIP，Key 仅保存在本机。解密结果可在 Finder 中打开，也可用 We Deck 打开 `.log` 文件并进入「用户日志分析」。
